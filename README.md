📊 CFF Submissions Admin Viewer (Single-File HTML)

This is a complete, single-file administrative interface for viewing, searching, and exporting form submissions stored locally via localStorage. It features a dark, neon-cyan theme with interactive particles on the login screen, and modern table sorting/filtering features.

🚀 How to Run

Save the file: Save the code above as admin_viewer.html.

Open in Browser: Double-click the file in your file explorer to open it in any modern web browser (Chrome, Firefox, Edge, etc.).
